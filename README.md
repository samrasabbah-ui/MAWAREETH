# MAWAREETH
مورد تعليمي مفتوح لمادة المواريث-إعداد سمراء صباح
 المواريث
مورد تعليمي مفتوح لتعلّم أحكام المواريث: شرح مختصر، الفروض الستة، حاسبة مواريث، مسائل محلولة، واختبار قصير.

رابط الموقع: https://samrasabbah-ui.github.io/MAWAREETH/

إعداد: سمراء صباح بالاستعانة بأداة الذكاء الاصطناعي كلود

صورة الغلاف أنشأتها سمراء صباح بالاستعانة بأداة ذكاء اصطناعي.
